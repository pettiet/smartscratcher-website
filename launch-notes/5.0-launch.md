## Launch-day checklist (single push, in order)

1. **Un-hold the exporters** (repo `ScratchSmart`, `ScratchSmartV2/Backend/`):
   - `export_public_games.py` → STATES adds:
     `'in': 'Indiana', 'md': 'Maryland', 'mi': 'Michigan', 'mo': 'Missouri', 'sc': 'South Carolina', 'va': 'Virginia', 'wa': 'Washington'`
   - `export_public_synopses.py` → STATES = 16 codes
     `['ca','fl','ga','in','ma','md','mi','mo','nc','nj','ny','ok','sc','tx','va','wa']`
   - `generate_site.py` → STATES adds:
     `'in': ('indiana', 'Indiana'), 'md': ('maryland', 'Maryland'), 'mi': ('michigan', 'Michigan'), 'mo': ('missouri', 'Missouri'), 'sc': ('south-carolina', 'South Carolina'), 'va': ('virginia', 'Virginia'), 'wa': ('washington', 'Washington')`
   - Commit to main, `scp` the three files to the droplet, reconcile droplet HEAD
     (`git fetch && git reset --mixed origin/main`).
2. **Merge this branch** (`feature/5.0-launch-articles`) into the website repo's
   main. It carries: both articles, the share-card template + rendered PNG,
   homepage state boxes (9 → 16), and blog-index cards.
3. **Re-render share cards** if the template changed:
   `python3 share/render.py seven-new-states` (droplet has Playwright).
4. **Publish**: run `/root/ScratchSmart/ScratchSmartV2/Backend/publish_public_games.sh`
   manually (or let the 10:45 AM cron do it). First run generates
   `/scratchers/<slug>/` pages for all seven states.
5. **Verify**: each new state page loads, homepage shows 16 boxes, article OG
   card renders (share debugger), app-store link campaign tag `ct=web-article`.
6. **Socials**: post FB/IG/X with `share/seven-new-states.png`; article link
   `https://www.smartscratcherapp.com/articles/seven-new-states.html`.

## Numbers cited in the articles (fact-check at launch)

- "over a hundred active games" (MI — 108 at launch) — safe unless MI drops below 100.
- "nearly ninety active games" (VA — 86 at launch) — safe range.
- WA "publishes exactly how many tickets each game printed" — factual, stable.
- MO "we filter the list down to games you can actually still buy" — factual (NLD exclusion).
- SC "fresh prize numbers post every morning" — factual (~10 AM ET stamp).
- IN "refreshes its numbers overnight, every night" — factual (~2:40 AM ET stamp).
- "From 9 → 16" — correct as long as no other state launches first. If OH etc.
  ships before this, update both articles' math.
