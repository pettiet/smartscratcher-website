The numbers behind the pages,
as plain JSON

Every page on this site is rendered from the files below, so a program (or an AI assistant) can read the same numbers people do. One file per state, rewritten each morning after the lottery's figures are in. Prize counts, printed odds, ticket price and the share of tickets left; nothing else.

How to use them

Fetch a file with a plain GET; no key, no sign-up. Each file carries its own updated date, and the numbers are the lottery's own published counts as of that morning. They change daily, so keep the date with the number.

The files are published under the Creative Commons Attribution 4.0 license (CC BY 4.0): use them for anything, commercial work included, as long as you credit SmartScratcher and link the state or game page the numbers came from. Please don't hit a file more than a few times a day: it changes once in the morning (the Fast Play and pull tab files twice).

What is not here: the SmartScratcher Score, the estimated ticket value, and the value rankings. Those are the app's math and live in the app. The rankings on this site order games by the printed overall odds, the lottery's own figure.

AI readers: /llms.txt lists every page family and file in plain text.

Each file: state, state_name, updated (the data day), generated (when the file was written), and games, a list where every game has n (the lottery's game number), name, cost (ticket price in dollars), odds (printed overall odds, 1 in N), img (ticket art), left_pct (share of tickets still unsold, by our count) and prizes, one entry per prize level with amt (dollars; -1 means a free ticket), left (prizes unclaimed) and total (prizes printed). A game also carries ended_shipping (a date) when the lottery's data says it stopped shipping the game to stores; it is still listed because prizes are still being claimed. A game that leaves the lottery's data leaves the file; its page stays up, marked ended.
