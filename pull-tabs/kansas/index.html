Kansas Pull Tabs:
what's still out there

Pull tabs are paper tickets you open instead of scratch, sold at bars and restaurants. Behind the scenes each game is a set pool of tickets with a set number of prizes, just like a scratcher. We track what's left in every pool, prize by prize, twice a day. The app turns these counts into a score and a ranking for each game.

What to look at before you pick

  1. Is the top prize still there? Each game starts with only a few. Many games keep selling after every top prize has been won.
  2. How many prizes are left at every level? Each game's page has the full table: what it started with and what is still out there.
  3. How many tickets are left? A game that is nearly sold out can be hard to find, and what is left is mostly small prizes.
  4. Which one is worth it? That is the app's job: a SmartScratcher Score, an estimated ticket value and a ranking for every game, under the Pull Tabs switch.

Quick answers

What are Kansas Lottery pull tabs?

They are paper tickets from the Kansas Lottery that you open instead of scratch. They are sold at bars, restaurants and other places licensed to sell Lottery products.

Is each ticket just random?

No. Each game is a set pool of tickets with a set number of prizes at every level, the same way a scratcher is. The lottery publishes how many prizes are left, and that is what these pages show.

Why do so many games show no top prize left?

Each game starts with only a few top prizes. Once they are won, the game keeps selling until its tickets run out. The "Top prize" column shows the biggest prize each game can still pay.

Are these numbers for the tickets at my bar?

No. The counts are for the whole state. They show what is left in a game across Kansas, not what is left in the tickets at one location.

How often is this updated?

Twice a day, in the morning and again in the late afternoon.
