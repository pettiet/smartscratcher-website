BETAKansas Pull Tabs:
which ones are worth it

Pull tabs are paper tickets you open instead of scratch, sold at bars and restaurants. Behind the scenes each game is a set pool of tickets with a set number of prizes, just like a scratcher. We track what's left in every pool and score each game from 0 to 100.

New to pull tabs? Many games keep selling after their top prizes are gone, and it changes which game is worth picking. Read the 2-minute guide →

What to look at before you pick

  1. Is the top prize still there? Each game starts with only a few. Many games keep selling after every top prize has been won.
  2. How much comes back per $1? A new game pays back more than one that has already lost its big prizes. The "Money back per $1" column shows today's figure.
  3. How many tickets are left? A game that is nearly sold out can be hard to find, and what is left is mostly small prizes.
  4. What's the score? The SmartScratcher Score rolls all of it into one number from 0 to 100.

How much of each $1 comes back

Longer bar, more money back on average. Each bar is an average across every ticket left in that game. It is not what one ticket pays.

A pull tab or a scratcher?

Scratchers have the bigger top prize at every price. Pull tabs give one ticket the better odds of winning the top prize on $1 tickets. Scratchers give one ticket the better odds of winning the top prize on $2 tickets. The typical pull tab game pays back more than the typical scratcher on $1 tickets. The two pay back about the same on $2 tickets.

Quick answers

What are Kansas Lottery pull tabs?

They are paper tickets from the Kansas Lottery that you open instead of scratch. They are sold at bars, restaurants and other places licensed to sell Lottery products.

Is each ticket just random?

No. Each game is a set pool of tickets with a set number of prizes at every level, the same way a scratcher is. The lottery publishes how many prizes are left, and that's what lets us work out what a ticket is worth today.

Why do so many games show no top prize left?

Each game starts with only a few top prizes. Once they are won, the game keeps selling until its tickets run out. The "Top prize" column shows the biggest prize each game can still pay.

Are these numbers for the tickets at my bar?

No. The counts are for the whole state. They show what is left in a game across Kansas, not what is left in the tickets at one location.

Is a pull tab a better buy than a scratcher?

It depends on the price. The "A pull tab or a scratcher?" table on this page compares the two at every ticket price they share, using today's numbers for both.

How is the score figured?

It's the same 0 to 100 SmartScratcher Score the app uses for scratchers. Most of it comes from how much a game pays back per dollar. The rest comes from how many top prizes are left and whether the odds have gotten better or worse since the game started.

How often is this updated?

Twice a day, in the morning and again in the late afternoon.

Not yet. We're testing them here first, and it's free while we do. The app covers scratch-offs today.
